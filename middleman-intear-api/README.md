# @sleet-js/middleman-intear-api

clean ts library for interacting with the Intear API (https://api.intea.rs).

```sh
bun i
# bun run build
bun run tsc
# publish
bun publish --dry-run
bunx npm login
bun publish --access public
# other
bun run tsc --noEmit
bunx prettier . --write
```
