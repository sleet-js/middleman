# @sleet-js/middleman-intear-api

clean ts library for interacting with the Intear API (https://api.intea.rs).

```sh
bun i
# bun run build
bun run tsc
# publish
bun publish --dry-run
bunx npm login
bun publish --access public
# other
bun run tsc --noEmit
bunx prettier . --write
```

---

Intear API
<br/>
https://docs.intear.tech/api/

the base url is `https://api.intea.rs`, no api key. every page of the
docs is also markdown, at its url with `.md` in place of the trailing
slash — <https://docs.intear.tech/api/llms-full.txt> has all of them in
one file.
